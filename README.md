# Tatakomotako · Таиланд

Мобильный статический гид для туристов: общая подготовка, Пхукет, Паттайя, сезонность, пляжи, острова, транспорт, чек-лист и помощь.

Откройте `index.html` или загрузите содержимое папки в GitHub Pages. Сайт работает без сборки и внешней базы данных. Отметки чек-листа сохраняются только в браузере пользователя.

Рабочая версия подготовлена для публикации в репозитории GitHub; цены и условия конкретных услуг перед продажей тура дополнительно сверяются по текущему меню, тарифу или ваучеру.
